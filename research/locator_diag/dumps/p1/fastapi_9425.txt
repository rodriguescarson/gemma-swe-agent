FILES: fastapi/routing.py:473-478
CAUSE: When the return annotation of a route function is `None` or `"None"`, `get_typed_return_annotation` returns `type(None)` (NoneType). This causes `self.response_model` to be set to `NoneType` instead of `None`, which triggers an `AssertionError` when `status_code=204` is used because FastAPI thinks a response body is defined.
FIX: In `APIRoute.__init__`, check if `return_annotation` is `NoneType` and set `response_model` to `None` in that case.
