## Discoveries

- **The Bug**: In `arrow/factory.py`, the `get` method accepts a `tzinfo` argument but fails to pass it to several factory methods. Specifically, when `arg` is a `datetime`, `date`, or `Arrow` object, the `tz` variable (extracted from `kwargs`) is ignored, whereas it is correctly used for strings and timestamps.
- **Affected Methods**:
    - `self.type.fromdatetime(arg)` should be `self.type.fromdatetime(arg, tz)`
    - `self.type.fromdate(arg)` should be `self.type.fromdate(arg, tz)`
    - `self.type.fromdatetime(arg.datetime)` for Arrow objects should likely include `tz`.
