## Root cause

- **Taxonomy: UNDERSPECIFIED_ISSUE plus HIDDEN_SPEC.** This confirms the old diagnosis. The issue text is only a link, and the expected output is an exact attribute string.
- **Feasible in 5 minutes: no.** No information in the task or the repository points to `<code>` font inheritance in the HTML export template; 0 of 19 runs found it.

## SOLVE

- **No bundle.** No repo-agnostic rule recovers an issue whose only content is an unreachable link and whose test pins an exact string. `docs/forty_two/queue/rich_3105.json` records `"bundle": null`.
