## Problem

- The issue is a maintainer PR titled "empty live"; the body is only "Fixes https://github.com/Textualize/rich/issues/3796".
- Bug: `Live.stop()` always calls `console.line()` on a terminal (unless alt screen), so a `Live` whose renderable produced no lines still leaves a blank line behind.
- Gold: 3 hunks, +17/-3. `rich/live_render.py` gets a `last_render_height` property (0 when nothing was rendered); `rich/live.py` `stop()` adds `and self._live_render.last_render_height` to the condition before `console.line()`. (The third hunk only reorders an import.)
- FAIL_TO_PASS (1): `tests/test_live.py::test_live_empty`. It runs `with Live(Group(), console=console, transient=True): pass` on the test file's capture console (`force_terminal=True`, `color_system=None`, width 20) and asserts `"\n" not in result` and `result == "\x1b[?25l\r\x1b[2K\x1b[?25h\r"`.
- PASS_TO_PASS: 10 tests in `tests/test_live.py`.

- **Which "empty" matters (measured, `r3934_kinds.py`).** `Text("")` and `""` render one blank line (shape `(0, 1)`); `Group()` and a renderable that yields nothing render none (`(0, 0)`). On base all of them write the newline. The test uses `Group()`.
- **What the test hides.** The exact control sequence. Both natural fixes measured here produce it: skip `console.line()` when the last render had no lines (gold-equivalent), or when it had zero width (`p3934_height.patch`, `p3934_width.patch`, both 11 passed). So the exact string is not a hidden-spec trap once the newline is gated on the rendered shape.

## Root cause

- **Taxonomy: UNDERSPECIFIED_ISSUE**, with the decisive mechanism an **environment blind spot**: the bug is in terminal-only output, and the sandbox's stdout is a pipe, so every repro that used a default `Console` printed nothing and the agents never observed the symptom. b1024 guessed the right input but could not see the result.
- **Feasible in 5 minutes: maybe.** For: the file is found at once; the terminal-forced, repr-printed repro shows the newline (measured); both natural ways of gating the newline on the rendered shape pass 11/11 (measured); tests cost ~2 s. Against: 0 of 6 box and 0 of 12 L4; the model must still connect "empty" with "a stray newline" and pick a shape-based condition (a fix keyed on `Text("")` alone, e.g. "skip when the text is empty", would not cover `Group()`; inferred).
- **General levers** (no task content):
  1. **The sandbox's output is a pipe: force terminal output in repros and print the repr.** Many libraries print less, no styling or nothing at all when stdout is not a terminal. When the issue is about printed or displayed output, turn on the library's own terminal switch in the repro, capture the output and print its `repr`. Built as `submissions/v13_tty_repro` (below).
  2. **Identical-command breaker** (already in the rich dossiers): p4 and v7c/v7d spent 94-210 s on identical repeats.
