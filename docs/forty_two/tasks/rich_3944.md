## Problem

- The issue is a maintainer PR titled "fix fonts"; the body is only "Fixes https://github.com/Textualize/rich/issues/3943".
- Bug: `get_character_cell_size` in `rich/cells.py` returns 0 for any code point above the last entry of the width table. Glyphs that Nerd Fonts place in the Supplementary Private Use Area (for example U+F024D) therefore measure 0 cells, and layouts that contain them come out too narrow.
- Gold: `rich/cells.py`, 1 hunk, +1/-1: that `return 0` becomes `return 1`.
- FAIL_TO_PASS (1): `tests/test_cells.py::test_nerd_font`: `cell_len("\U000f024d") == 1` (comment: "Not allocated by unicode, but used by nerd fonts").
- PASS_TO_PASS: 53 tests in `tests/test_cells.py`.
