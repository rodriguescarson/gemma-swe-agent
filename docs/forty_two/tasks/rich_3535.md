## Problem

- The issue is a maintainer PR titled "Regex error": "Fixes an issue with the regex used to select the fast path for strings with single-width characters. This may have had a detrimental effect on performance for some operations." No file, identifier or example.
- Bug: `rich/cells.py` line 10, `_is_single_cell_widths = re.compile("^[ -o ˿Ͱ-҂]*$").match`. The first range stops at `o` (0x6F) instead of `~` (0x7E), and ` ˿` lacks its hyphen. Strings with `p`-`~` miss the fast path (correct but slow).
- Gold: 2 hunks, +7/-1. `rich/cells.py`: ranges become ` -~`, ` -˿`, `Ͱ-҂` **and a new `─-◿`** (box drawing and block elements). `rich/segment.py`: a docstring and `assert cut >= 0` in `split_cells` (untested).
- FAIL_TO_PASS (1): `tests/test_cells.py::test_is_single_cell_widths`. It asserts the fast path matches every printable ASCII character, **every box-drawing character in `┌─┬┐│ ││├─┼┤...└─┴┘`**, and does not match two emoji and three kana.
- PASS_TO_PASS: 7 tests in `tests/test_cells.py`.

## Root cause

- **Taxonomy: HIDDEN_SPEC.** The stated bug (ASCII range) was fixed by every run. The test also requires the box-drawing block in the fast path, which the gold adds as an optimisation and nothing visible to the agent mentions (issue, comment, history).
- **Feasible in 5 minutes: no.** Location and the stated fix take under a minute on every pipeline; the remaining requirement is a choice of which extra Unicode block counts as "most common". The model could only reach it by reasoning that the library's own tables and panels emit box-drawing characters, and 0 of 18 runs (6 box, 12 L4) did.
- **General levers** (no task content), none built:
  1. **Probe a fast path with what the library itself emits.** When fixing a predicate that gates a fast path, run it on the library's own typical output (here, a rendered table) as well as on the issue's example. Too narrow to justify a prompt line (inferred: one task in 74).
  2. **Sibling sweep inside one expression.** b1024, v0-think and p4 fixed one range and left the missing hyphen two characters to the right. The prompt's sibling rule names branches and functions, not neighbouring tokens. Not tested by this task's F2P, so it would not flip it.
