## Problem

- The issue is a maintainer PR titled "fix background style with soft wrap"; the body is only "Fixes https://github.com/Textualize/rich/issues/3838".
- Bug: `Console.print(..., style=..., soft_wrap=True)` applies the style to the whole rendered segment stream, newline included, so the background colour is emitted around the `\n` and bleeds into the next line.
- Gold: 2 hunks, +40/-5. `rich/segment.py` gains a new classmethod `Segment.split_lines_terminator(segments)` that yields `(line_segments, had_newline)` pairs; `rich/console.py` `print()` uses it to style each line and append an unstyled `Segment.line()`.
- FAIL_TO_PASS (3):
  - `tests/test_text.py::test_soft_wrap_styled`: on a `force_terminal=True`, `color_system="standard"` console, `print("soft wrap is on", style="blue on white", soft_wrap=True)` then `print("Next line")` must give `"\x1b[34;47msoft wrap is on\x1b[0m\nNext line\n"`.
  - `tests/test_segment.py::test_split_lines_terminator` and `::test_split_lines_terminator_single_line`: call the new method by name and pin its return shape: `[Segment("Hello\nWorld")]` -> `[([Segment("Hello")], True), ([Segment("World")], False)]`.
- PASS_TO_PASS: 171 tests across the two files.
